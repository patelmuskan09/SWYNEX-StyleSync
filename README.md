# StyleSync

### Fashion and Wardrobe Management Platform

## About the Project

StyleSync is a fashion and wardrobe management web application designed to help users organize their clothing collections, explore fashion products, create outfit combinations, and save their favourite products.

## Objectives

- Organize personal clothing collections.
- Browse clothing products by category.
- Create and manage outfit combinations.
- Maintain a personal wishlist.
- Provide an organized fashion management experience.

## Technology Stack

- React.js
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Cloudinary

## Main Features

- User registration and login
- Personal wardrobe management
- Clothing catalogue
- Outfit planner
- Wishlist management
- Admin dashboard

## Project Structure

The project will follow a client-server architecture with separate frontend and backend components.
